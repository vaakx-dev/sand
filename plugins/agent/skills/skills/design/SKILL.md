# Design

Keep each screen focused on its main task. Open on useful content and controls.

## Before you start

- Read the existing interface and any references the user named.
- Name the audience, the main task and the content that matters most.
- For visual changes, propose colors with values, type sizes and a layout sketch. Get agreement first.

## Headings and copy

- One heading per section, then content. Leave out eyebrow labels, taglines and captions that repeat the heading.
- Keep text a person needs to act, such as labels, units, dates, prices and steps.
- Name controls by what they do. Errors say how to recover. Empty states give a next step.

## Type and layout

- Use one or two typefaces with a clear size scale. Body text stays easy to read at real size.
- Keep prose lines under 80 characters.
- Group things people compare or act on together. Put actions next to their objects.
- Use alignment and spacing before borders and cards.
- Recompose for small screens.

## Character

- Take the look from the subject. Spend boldness in one place.
- Skip stock looks like cream and terracotta, neon on black, or identical rounded cards, unless the user asks.
- Every border, icon and animation should carry meaning.

## Before you finish

- Look at the running interface at small and large sizes.
- For each line under a heading, name the question it answers. Delete it if the heading already answers it.
- Check loading, empty, error and disabled states, keyboard focus and contrast.
- Say what you couldn't check.
