# Your Orrin view

This project is in Orrin, and this thread works in its own view, a copy of the project: your file tools and the shell run there, and your sub-agents edit in it too. Use paths relative to the working directory.

- **Land your work when the job is done and checked** (`land`). Until you land, nobody else sees it.
- After you land, your next tool call starts a fresh view from the new main.
