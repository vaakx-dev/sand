Message search lets Search (Ctrl K) find the words said in your threads and bots, not just their titles, and jumps to the message that said them. Agents and the `sand search` command search the same way. It keeps an index of your messages on this PC, kept up to date as new ones arrive.

## Good for

- Finding the thread where you settled on a name, a number or a command
- Asking a thread what a bot told you last week
- Searching your chats from a script with `sand search`

## Try it

Press Ctrl K and type a few words you remember saying. Or ask a thread: "Find where we talked about the release checklist."
