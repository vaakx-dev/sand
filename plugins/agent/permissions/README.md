Permissions make threads and bots ask before risky calls, like running commands, sending messages, spending money, deleting things or touching files outside the project folder. Pick a mode for each thread or bot: Off runs every call, Ask asks you, and Auto lets a reviewer model decide and asks you only when it keeps saying no. Saved rules remember your answers, and a log shows every decision.

## Good for

- Letting a bot work overnight without it deleting your thesis folder
- Trying an agent on a new project while you watch what it runs
- Giving threads a bot starts stricter rules than your own

## Try it

Open a thread, set its permissions to Ask, and ask: "Clean up the build folder." Answer the question that pops up.
