Follow pull requests keeps a thread up with the pull requests it opens. The thread wakes when CI finishes, a review or comment lands, or the PR closes or conflicts, and deals with it, so you don't have to come back and tell it the tests failed. Once its pull requests merge, the thread is archived.

## Good for

- Fixing a failing CI run without you watching the checks
- Answering review comments on a group project's repository
- Rebasing when someone else's merge causes a conflict

## Try it

Ask a thread in a git project: "Fix the off-by-one in the timestep loop and open a pull request." Then leave it to follow the PR.
