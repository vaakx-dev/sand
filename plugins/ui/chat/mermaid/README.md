Mermaid diagrams draws the flowcharts, sequence diagrams and charts agents write in Mermaid, in the chat and in the file viewer. You see the picture instead of the code that describes it.

## Good for

- A flowchart of an algorithm before you code it
- The steps of a lab procedure or a control loop at a glance
- A sequence diagram of how a client and a server talk

## Try it

Ask: "Draw a Mermaid flowchart of how a PID controller updates its output each step."
