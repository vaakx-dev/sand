Thread usage shows what a thread and its subagents cost in its Details card, per model. You see where the tokens went before the bill does.

## Good for

- Keeping a semester project inside a small budget
- Comparing what a big model and a small one cost for the same task
- Spotting the subagent that read far more than it needed

## Try it

Ask a thread to do some work, then open its Details and look at the usage card.
