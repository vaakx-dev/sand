File viewer opens the files your agents write and mention beside the chat: text, code, Markdown, images, audio and video. Tap a file name in a reply to see it without leaving the thread. Its extras add more formats, like PDF, office documents, notebooks and SQLite databases.

## Good for

- Reading the report an agent just drafted next to the conversation
- Checking a plot or a photo a script saved
- Skimming a config file or a log an agent points you to

## Try it

Ask a thread: "Write a short Markdown summary of pendulum.py to notes.md." Then tap notes.md in the reply.
